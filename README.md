# physical-ai-corp-project

> **AI 협동로봇 기반 공장&창고 안전관리 시스템**  
> 청년 피지컬AI 2기 · 10팀 포텐 기업 과제 주차별 기록 저장소

[웹에서 보기 (목차)](https://myeongsu-dev.github.io/physical-ai-corp-project/)

MechDog 4대가 대피 통로를 순찰하며 막힘·바닥 물건을 찾아 사람이 치우게 하고, 화재 때는 막힌 길을 피해 비상구로 안내하는 프로젝트를 정리해 둡니다.

## 프로젝트 정보

| 항목 | 내용 |
|---|---|
| 팀 | 10팀 포텐 (박명수 · 이예은 · 채웅 · 김건주) |
| 멘토 | 류찬무 |
| 기간 | 2026. 11. 04 ~ 12. 21 |
| 교구 | MechDog 4대 · 센서·비전 확장 모듈 |

## 주차별 기록

### 1주차 · 11. 09 ~ 11. 13 (`week01/`, 1회차 멘토링)

| 번호 | 문서 | 내용 |
|---|---|---|
| 01 | 주제 선택 · 배경 | 무엇을, 왜 만드는지 · 주제가 정해진 과정 · 출처 |
| 02 | 기능 정의서 | 시스템 구성, 기능 목록과 우선순위, 뺀 기능, 3D 장착 모델 |
| 03 | 미션맵 · 시연 구성안 | 시연 무대 구성, 순찰 규칙, 시연 순서와 시뮬레이션 |
| 04 | 미션맵 재료 목록 | 외부 구매, 자체 제작, 구조물 배치 원칙과 11/16 신청 정리 |

### 2주차 · 11. 16 ~ 11. 20 (`week02/`, 2회차 멘토링)

| 번호 | 문서 | 내용 |
|---|---|---|
| 01 | 시스템 아키텍처 | 장치 구성, 판단 위치, 통신, 주요 흐름, 소프트웨어 구조, 먼저 확인할 것 |

## 폴더 구성

```text
physical-ai-corp-project/
├── index.html                  # 주차 선택 페이지 (웹 포털)
├── assets/                     # 모든 문서가 같이 쓰는 스타일·스크립트 (목록은 assets/README.md)
│   ├── doc.css · doc.js        # 문서 공통 컴포넌트 (표 · 배지 · 요점 상자 · 상단 바 등)
│   ├── diagram.css · diagram.js # 그림 도형 재료, Mermaid 불러오기
│   ├── index.css               # 목차 페이지
│   ├── components.html         # 컴포넌트 견본
│   ├── diagrams.html           # 그림 형태별 견본
│   ├── template.html           # 새 문서 틀
│   ├── 3d/                     # 3D 장착 모델 위젯 (viewer.js) · 부품 GLB
│   └── sim/                    # 미션맵 시뮬레이션 위젯 (missionmap.js)
├── week01/                     # 1주차 (11/09~11/13) 산출물
│   ├── index.html              # 1주차 문서 목차
│   ├── 01_주제선택_배경.html
│   ├── 02_기능정의서.html
│   ├── 03_미션맵_시연구성안.html
│   └── 04_재료_목록.html
├── week02/                     # 2주차 (11/16~11/20) 산출물
│   ├── index.html              # 2주차 문서 목차
│   └── 01_시스템_아키텍처.html
└── 2026-11-13/                 # 예전 주소 연결 페이지 (열면 week01 같은 문서로 이동)
```

산출물은 만든 주의 `weekNN/` 폴더에 두고, 내용이 바뀌면 그 자리에서 계속 고칩니다. 주차는 월~금 기준이며 1주차는 11/09~11/13입니다. 문서 이름은 `번호_제목.html`이고, 번호는 그 주 안에서 이어 붙입니다.

문서는 본문만 담고 생김새는 `assets/`의 공통 컴포넌트에서 가져옵니다. 새 문서는 `assets/template.html`을 주차 폴더에 복사해 시작합니다. 회의 폴더(`archive/…/assignment/`)의 원본은 회의 때 기록으로 남기고, 공개한 뒤에는 이 폴더의 문서만 고칩니다.
