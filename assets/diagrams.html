그림 도형 어휘 견본

diagram.css · diagram.js · diagram.json 기반 형태별(data-kind) 9종 견본

모든 그림은 figure.fig[data-kind] + figcaption으로 감싸고, SVG는 role="img"와 aria-label을 갖춘다.

1. blocks — 장치·층·연결 구성도

이럴 때 쓴다: 장치·계층·모듈 사이 유선(.ln.wire)과 무선(.ln.air, 점선은 .dashed) 연결 관계를 보여 줄 때. 선·테두리·글자 색은 .c-blue 같은 색 지정 클래스로 바꾼다.

색 지정 클래스 (.c-*) 견본

이럴 때 쓴다: 상태(.ok·.warn·.err·.mute)와 무관하게 원래 그림의 선·면 테두리·글자·화살촉 색을 그대로 옮길 때.

2. sequence — 시간순 주고받기

이럴 때 쓴다: 장치·서버·사람 사이 메시지 순서와 왕복 흐름을 보여 줄 때.

3. state — 상태와 전이 조건

이럴 때 쓴다: 로봇이나 시스템이 갖는 상태들과 상태가 바뀌는 조건을 정리할 때.

4. flow — 분기·판단 흐름

이럴 때 쓴다: 조건에 따라 갈라지는 판단 절차나 단계별 처리 흐름을 보여 줄 때.

5. timeline — 시간·장면 순 진행

이럴 때 쓴다: 시연 장면 순서나 주차별 진행 일정을 시간 축으로 나란히 놓을 때.

6. map — 공간·동선 약도

이럴 때 쓴다: 실제 공간 배치, 한 방향 동선, 갈림길 위치를 평면 위에 그릴 때.

7. tree — 폴더·계층 구조

이럴 때 쓴다: 저장소 폴더 구조나 메뉴·구성 요소의 상하 계층을 텍스트 그대로 보여 줄 때.

8. chart — 수치·막대·추이 그래프

이럴 때 쓴다: 로봇별 배터리 잔량, 전압, 추론 지연 같은 수치 비교를 막대나 점으로 그릴 때.

9. custom — 규격 틀에 안 맞는 자유 그림

이럴 때 쓴다: 센서 시야각이나 로봇 단면처럼 앞의 정형 형태에 맞추기 어려운 그림을 자유 SVG로 그릴 때.
