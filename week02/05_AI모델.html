AI 모델

라즈베리 파이 5에서 돌릴 안전모 · 불꽃 모델의 구성, 데이터, 라벨링, 학습과 변환, 평가

작은 YOLO 모델 두 개를 따로 학습해 라즈베리 파이 5 CPU에서 돌린다. 안전모 모델은 순찰 중 늘, 불꽃 모델은 화재가 의심될 때만 돌린다.

1. 모델 구성

모델클래스언제 돌리나쓰는 기능
안전모 모델person · head · helmet순찰 중 늘F-06 · F-07 안전모 착용 확인 · 보행자 구분
불꽃 모델fire온도 센서가 화재를 의심할 때만 (Pi 5 CPU 부담을 줄임)F-05 · F-10 화재 감지 · 교차 확인

몇 장 중 몇 장으로 확정하는지, 몇 도에서 의심하는지 같은 판정 기준은 기능 정의서 4절.

2. 데이터

  • 출처: 멘토가 주는 안전모 · 불꽃 데이터셋 + 공개 데이터(Roboflow · Kaggle · AI Hub · COCO) + 미션맵에서 XIAO로 찍은 사진
  • 카메라 화질: 실제로 쓰는 ESP32 카메라 화질로 찍은 사진을 꼭 섞는다
  • 균형: 모델마다 클래스별 사진 수를 비슷하게 맞춘다
  • 다양성: 안전모는 정면만이 아니라 옆 · 뒤 · 위에서 본 모습과 여러 색을 넣어, 학습 사진에만 맞춰지지 않게 한다

3. 라벨링

모델을 맡은 두 사람이 하고, 자동 라벨 결과를 무작위로 골라 사람이 검수한다. 사람이 로봇을 가르치는 협동 장면으로 발표에도 쓴다.

4. 학습과 변환

항목내용
학습 환경팀에 GPU가 없어 CPU 학습은 오래 걸린다. Colab 무료 GPU와 Vast.ai(남는 GPU를 시간 단위로 빌림, 시간당 약 0.2~0.35달러)를 후보로 두고 멘토와 정한다
변환학습한 모델을 Pi 5 CPU용으로 바꾼다 (NCNN 등, 입력 320~640). 추론 가속 보드(Hailo) 없이 CPU로만 돌린다
배포Pi의 models/에 버전을 붙여 넣는다 (방법은 시스템 아키텍처 6절 업데이트)
진행학습을 돌려 두고 기능 구현을 함께 진행한다

5. 평가

모델이 낸 답을 사람이 적은 정답표와 비교해 센다. 처음 목표는 10번 중 5번이고, 자주 틀리는 상황의 사진을 더 넣어 다시 학습한다.

지표뜻 (화재 예)
TP · FP · FN불이라고 했고 진짜 불(정탐) · 불이라고 했는데 아님(오탐) · 진짜 불을 놓침(미탐)
정밀도불이라고 한 것 중 진짜 불의 비율. 오탐이 많으면 떨어진다
재현율진짜 불 중 찾아낸 비율. 화재는 놓치면 위험해 이 값을 먼저 본다
F1 · mAP@0.5F1은 정밀도와 재현율의 조화 평균. mAP@0.5는 예측 상자와 정답 상자가 절반 이상 겹치면 맞힌 것으로 쳐서 낸 평균 정확도로, YOLO 모델을 비교할 때 쓴다
  • 화재: 불을 여러 번 낼 수 없어 영상과 실외 불(가스버너 · 신문지)로 평가한다
  • 안전모: 사람이 직접 쓰고 벗으며 미션맵 거리(1~3m)에서 시험한다
