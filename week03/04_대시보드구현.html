대시보드 구현

담당 이예은 · 관제 화면 dashboard/ · 2026. 11. 26 기준 (PR #12 · #15는 dev에 합쳐짐, 그 뒤 작업은 dashboard/plan 브랜치)

로봇 4대의 연결 · 상태 · 위치 · 배터리와 경보를 한 화면에서 보고, 관리자가 경보 해제와 대피 해제를 한다. 화재는 서버가 교차 확인으로 확정해 대피 모드로 바꿀 때만 표시한다. 서버와 로봇 사이가 끊기면 5초 안에 화면에 표시된다.

1. 화면

주소는 두 개입니다. 기본 화면 http://서버:8000/은 누구나 보는 현황판이고, 관리자 화면 http://서버:8000/?admin은 경보를 처리하는 화면입니다.

기본 화면
  • 위 막대: 서버 연결, 로봇 연결 대수(예: 4/4대), 시각, 로봇 끊김 알림
  • 미션맵: 구역, 순찰 통로, 마커, 비상구, 충전 스테이션
  • 안전 현황: 안전 · 주의 · 화재와 경보 건수(과열 · 불꽃 감지, 통로 차단, 밟힘 주의). 화재는 대피 모드일 때만
  • 최근 경보: 해제 안 된 경보 5개
  • 대피 모드면 맨 위에 빨간 띠("화살표 방향의 비상구로 대피하세요")와 지도에 화재 위치 · 대피 화살표
관리자 화면
  • 지도 위 로봇 위치. 끊긴 로봇은 마지막 위치에 회색 점선
  • 로봇 현황: 연결, 상태, 위치(예: A 경로 · 마커 8), 배터리, Pi 프로그램 버전
  • 경보 알림: 통로 차단은 팝업과 경보음 2번. 과열 · 불꽃 감지 · 밟힘 주의는 목록에서 깜빡임과 1번. 대피 모드가 되면 3번을 3초마다 반복("경보음 멈춤"이나 대피 해제로 멈춤)
  • 경보 상세: 사진, 시각, 로봇, 경로, 위치, 신뢰도, 온도, 사람 여부
  • 경보 해제와 대피 해제. 대피 해제는 누르기 전에 한 번 더 확인
  • 경보 이력: 해제한 경보도 사진까지 다시 봄. 해제 칸은 "해제 전" · "경보 해제"

2. 만든 방식

항목내용
빌드 없음프레임워크 없는 HTML · CSS · JavaScript를 서버(server/api.py)가 그대로 내줌. 설치 없이 열고, 작은 장비에서도 돎
서버와 주고받기WebSocket 하나로 상태 · 경보 · 모드를 계속 받고, 경보 해제와 대피 해제만 HTTP(POST /events/{id}/check 등)
가짜 서버주소 뒤에 ?fake면 서버와 같은 모양의 메시지를 보내는 dashboard/js/fake.js로 화면을 만듦. 서버 파트와 동시에 개발
계산과 그리기 분리안전 · 주의 · 화재 판단, 연결 여부 같은 계산을 화면과 나눠 브라우저 없이 시험
CIPR마다 셀프 체크. 지도 마커와 연결 판단 기준(5초)이 서버 설정과 같은지도 확인해서 한쪽만 바뀌면 알려 줌

3. 정한 것

  • 화재는 서버가 정함: 화면은 서버보다 먼저 화재라고 하지 않음. 로봇 한 대가 본 불꽃은 "불꽃 감지"(주의)이고, 서버가 대피 모드로 바꿔야 화재
  • 경보마다 알리는 정도를 다르게: 통로 차단만 팝업, 과열 · 불꽃 감지 · 밟힘 주의는 목록에서 깜빡임, 화재(대피 모드)는 빨간 띠와 반복 경보음
  • 되돌리기 어려운 동작은 한 번 더 확인: 대피 해제
  • 기본 화면은 작업자용: 로봇 현황과 경보 이력은 관리자 화면에만. 작업자는 로봇 상태로 할 일이 없고, 사진에 사람이 찍힐 수 있어서
  • 끊겨도 숨기지 않기: 끊긴 로봇은 마지막 위치와 마지막 수신 시각을 남김. 대피 중에 서버가 끊겨도 대피 표시는 내리지 않음
  • 현장 말: "경보 해제", 로봇 이름은 화면에서만 MD-1~MD-4. 서버 · Pi와 주고받는 이름은 A~D 그대로
  • 경보음은 버튼으로 켬: 브라우저는 한 번 누르기 전에는 소리를 막아서 "경보음 켜기" 버튼을 두고, 막혔을 때는 화면에 알림

4. 연결 끊김 시험

서버가 5초 넘게 state를 못 받으면 online: false를 한 번 보내고, 대시보드는 받는 즉시 끊김으로 표시합니다. 마지막 수신 시각은 서버가 보내는 seen_ago로 계산해서 새로고침해도 남습니다.

시험확인한 것상태
가짜 로봇 4대끄면 약 5초 뒤 끊김, 새로고침해도 마지막 수신 시각 유지, 다시 켜면 연결완료
Pi 프로그램 1대 (가짜 장치)끊김 표시, 막힘 · 과열 경보와 사진이 대시보드까지 옴완료
실제 MechDog연결 · 순찰 · 배터리 표시는 1차 통합 시연에서 확인. 실기 끊김은 Wi-Fi 끊김 단계로 남음확인 중
